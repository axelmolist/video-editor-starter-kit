# video/projects

Your projects live here, one folder per video. This folder is gitignored apart from this file.

```
video/projects/<format>/<slug>/
  raw-footage/      the source files, untouched
  editor-files/     everything the agents make while working (transcripts, EDLs, renders, scopes)
  final-footage/    the deliverables, versioned -vN, never overwritten
```

Formats: `youtube-long/`, `podcasts/<show>/<episode>/`, `shorts/`, `youtube-vlog/`.
